Politique de confidentialité

Dernière mise à jour : 2 septembre 2026

Kocott est une application de recettes 100 % locale : pas de compte, pas de serveur, vos recettes restent sur votre appareil. Cette page explique précisément ce qui est collecté — et surtout, ce qui ne l'est pas.

Éditeur

Kocott est développée et éditée par Robin Landraud, développeur indépendant. Pour toute question relative à cette politique, voir la section Contact ci-dessous.

Une application locale par conception

Kocott ne demande aucune création de compte et ne fait transiter vos recettes par aucun serveur. Toutes vos données (recettes, ingrédients, favoris, préférences) sont stockées uniquement sur votre appareil, dans une base de données locale (SQLite). Elles restent inaccessibles à l'éditeur de l'application, qui n'y a lui-même aucun accès à distance.

Partage de recettes (QR code / code texte)

Lorsque vous partagez une recette, celle-ci est encodée directement dans un QR code ou un code texte, sans passer par un serveur intermédiaire. La transmission se fait uniquement entre votre appareil et celui de la personne qui scanne ou colle le code — de main à main, comme on tendrait une fiche recette.

Import depuis une URL

Si vous importez une recette depuis un lien, votre appareil se connecte directement à la page indiquée pour en extraire les informations, de la même manière qu'un navigateur web classique. Aucune donnée n'est envoyée à un serveur Kocott à cette occasion — l'éditeur de l'application n'a connaissance ni de l'URL importée, ni de son contenu.

Publicité (Google AdMob)

Kocott affiche des publicités à certains moments (par exemple après un import ou un export PDF) via le service Google AdMob. Pour cela, Google peut collecter et traiter, via son SDK intégré à l'application :

  • un identifiant publicitaire propre à votre appareil (permettant, sauf refus de votre part, un ciblage publicitaire) ;
  • des informations techniques sur votre appareil (modèle, version du système, opérateur, données de connexion approximatives).

Ces données sont traitées par Google en tant que responsable de traitement indépendant, selon sa propre politique de confidentialité, consultable ici : policies.google.com/privacy. Le partage QR code / code texte entre deux appareils Kocott, lui, ne déclenche jamais de publicité.

Permissions de l'appareil

L'application peut demander l'accès à la caméra, utilisée uniquement pour scanner le QR code d'une recette partagée — aucune photo ni vidéo n'est enregistrée ou transmise. Le module caméra utilisé en interne peut, au niveau du système, demander également l'accès au microphone ; Kocott n'utilise cependant aucune fonctionnalité audio.

Vos droits

Puisque vos recettes ne quittent jamais votre appareil, vous en gardez la maîtrise complète : les modifier ou les supprimer directement dans l'application suffit à les effacer définitivement, sans qu'aucune copie ne subsiste ailleurs.

Concernant les données traitées par Google AdMob, vous pouvez à tout moment :

  • gérer votre consentement à la publicité personnalisée depuis le formulaire proposé dans l'application ;
  • réinitialiser ou limiter votre identifiant publicitaire depuis les réglages de votre appareil Android (Paramètres → Confidentialité → Publicité) ;
  • consulter et gérer vos préférences publicitaires Google sur myadcenter.google.com.

Confidentialité des enfants

Kocott n'est pas conçue spécifiquement pour les enfants et ne collecte sciemment aucune donnée personnelle auprès de mineurs.

Modifications de cette politique

Cette politique peut évoluer, notamment si de nouvelles fonctionnalités impliquant un traitement de données sont ajoutées à l'application. La date de dernière mise à jour en haut de page reflète toute modification.
